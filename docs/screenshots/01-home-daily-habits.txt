VIEW-SPECIFIC
Week navigation, clickable **Week grade** (curved mean of elapsed daily %; 0% stays 0; scrollable raw/curved day breakdown + tolerance + 50/100/300 point notes and +50 when raw day >80%) and **Perfect output** (curved mean of elapsed row %; scrollable per-habit breakdown + separate tolerance), frequency tabs (Daily/Weekly/Monthly), hide-completed toggle, Settings, and a compact spreadsheet (all 7 days + per-habit week % with gradient progress bars). Habit names can show `4+` / `🔥 Nw` week-streak chips. Column headers are weekday + numeric date (`Mon` / `9/14`). Climb (incremental) rows look like goal cells (`value / target`). Daily climbs use last log + increment (a drop still lowers tomorrow’s target); weekly climbs keep a fixed weekly target. Completing a daily habit awards 50 points × that day’s completion (partial counts) and can add +50 (raw day >80%) / +100 / +300 grade bonuses; it also appears in To-Do **Done**. The floating Add control opens a Win95 **Add New Habit** window with Climb cadence tiles (Weekly + / Daily +). Points stats and Today's Progress cards sit above the sub-tabs; Needs Attention surfaces stale or blocked items.
