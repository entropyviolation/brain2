# `components/` — All React UI

Every React component in Brain2 lives here. Top-level files are cross-cutting dialogs and shared widgets; each subfolder is one **module** surfaced from the main tab bar in `app/page.tsx`.

Brain2 is meant to be a **living, perfect second brain** — adaptable, alive,
beautiful, a new type of software. These folders are rooms on **one item
graph**, not a suite of separate products: an item captured once should be
connected and used in as many of them as it can honestly serve. **Data**
is the heart: analytics and combined analysis over the vault, visualization
and stats, spreadsheet-style libraries for viewing the rows, sources such as
Instagram, texts, and browser history, and screens whose job is to clean,
annotate, correct, or confirm the data. The suites ship; the plain libraries
and the annotation pass are **Planned**
([`Analytics/README.md`](Analytics/README.md)). A record is a map: dated, incomplete, and kept at
its own order. Description stays distinct from inference. Look and feel: **Lists** (`Lists/`) is the
gold-standard combination of Win95 furniture and surreal orb/velvet contents.
New UI should preserve both halves — [`docs/DESIGN_STYLE.md`](../docs/DESIGN_STYLE.md). A word key is the silver [keycap](../docs/DESIGN_STYLE.md#keycaps) there; seafoam and cornflower are the spare plastics. [The screen stays pleasing](../docs/DESIGN_STYLE.md#the-screen-stays-pleasing) overrides a local packing note.
The build that extends the map is [`docs/ScienceandSanityBrain2.md`](../docs/ScienceandSanityBrain2.md).

## Public door

`AppHeader.tsx` is the pin bar. It mounts `header-now-box.tsx` (`HeaderNowBox`)
inside Capture (idle → hidden). `header-doors.tsx` keeps the Inbox, Quick Add,
Rituals, and Settings keys on that bar. The Quick Add key also mounts
`QuickAddWroteHost` so the floating "added" confirmation outlives the dialog.
Those rooms load the first time they open, so a refresh does not download a
closed door. The Now key stays in
`cognitive-state.tsx`; its popup loads when Now opens. A Settings bay loads
when that bay is selected. The first Rituals press loads the menu; the next
press opens it. The shared clock hook is `useWorkSessionClock` from
`Operations/WorkingNowControl.tsx`. `Home/Tracking/working-now-strip.tsx` is
the Tracking strip. Other rooms may import the header well and the hook.
They may not fork a second timer.

## From Notes (Apple Notes ingest)

**From Notes** (`notes-ingest.tsx`), opened from Settings and from Lists settings (**Notes and ingest**). Reads **Notes.app on this Mac** (iCloud and On My Mac). The dialog title is **Notes on this Mac**. Electron uses `window.desktop.fetchAppleNotes`; Chrome at `http://localhost:3000` uses the same reader through `/api/notes` (loopback only). A phone browser cannot list Notes. The first run may prompt macOS Automation permission for Notes. Listing walks each Notes folder and reads titles in bulk — it does not ask Notes for the whole library at once.

Flow:

1. Pick a **date range** (dialog opens immediately; listing shows the scope instrument). Closing the dialog does **not** cancel listing — **From Notes** / **Resume Notes** / **Listing…** on that same button brings the session back. **Continue in background** is the same dismiss. **Done** or closing the finished empty screen starts a fresh period next time.
2. **Parse / skip** each note. The card shows the **title plus a content preview** (snippet fetched per card, not the whole library).
3. For each parsed note: freely edit **bulk-add** syntax (`ListName:` then items), or **Save for later ingestion**.
4. Parked notes go in an auto-created Lists folder **Mac Notes**, list **notes to ingest**, with the **full note body** (not title-only). A folder still named **iPhone Notes Ingest** is renamed to **Mac Notes** the next time a note is parked. Bulk-add writes real items onto the named lists.

Header syntax is the same rule as Quick/Bulk Add (`parsePathHeader`), so a second colon names a **new folder**: `Trip ideas: Packing:` files the items on a new **Packing** list inside a new **Trip ideas** folder. Both notes dialogs resolve destinations through `ensureCaptureTarget`, the same door Quick Add uses, so nothing is created twice.
5. Apple Note ids that were already bulk-added or parked are **skipped** on later runs (`appleNoteId` on items + `cogs-apple-notes-ingested-ids`).

Helpers: `lib/apple-notes.ts`. Native reader: `electron/apple-notes.js` + `electron/apple-notes.jxa` (modes `preview` / `snippet` / `bodies`). Local `npm run dev` also serves `/api/notes` (`scripts/notes-api.mjs`, loopback).

## Phone Notes (iPhone Notes Store)

**Phone Notes** (`iphone-notes-store.tsx`), opened from Settings and from Lists settings (**Notes and ingest**). The mobile shell still shows this button on its top bar. On My iPhone notes that never sync to this Mac: generate the signed shortcut with `npm run shortcut:iphone-notes` ([recipe](../docs/shortcuts/dump-iphone-notes-to-brain2.md); the `.shortcut` is not in the repo, and `.wflow.json` will not import). It dumps `iphone-notes:` to the Telegram bot; Brain2 parks full bodies on Lists → **iPhone Notes Store** → **Parked** (`ensureIphoneNotesStoreDestination`).
